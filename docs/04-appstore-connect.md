以下字段按 2026-07-23 的 App Store Connect 结构准备。账号、域名、证书和 Bundle ID 中的占位符需要开发者替换。

## 1. 新建 App

| 字段 | 填写内容 |
|---|---|
| 平台 | iOS |
| 名称 | 钣金展开-放样展平计算器 |
| 主要语言 | 简体中文（zh-Hans） |
| Bundle ID | `com.<developer>.banjinzhankai` |
| SKU | `BANJIN-ZHANKAI-IOS-001` |
| 用户访问权限 | 完全访问，或按团队实际设置 |

注意：

- Bundle ID 创建后不能随意变更，先将 `<developer>` 替换为自己的反向域名。
- App 名称可能在创建时被占用；如占用，优先保留“钣金展开”，备选为 `钣金展开-现场放样计算器`。

## 5. 截图与图标

### App 图标

- 1024 × 1024 px。
- 不使用透明通道。
- 建议图形：板材折线/展开轮廓＋尺寸箭头。
- 避免在图标中塞入“钣金展开”等小字。
- 不使用 Apple、AutoCAD、标准组织或竞品商标。

### 截图

- 至少准备一组当前 App Store Connect 接受的 iPhone 最大规格截图。
- 根据后台提示补齐必要设备尺寸。
- 使用 `03-ios-metadata-aso.md` 的 7 张截图结构。
- 截图必须展示实际 App 界面，不能承诺未上线功能。

### App Preview

V1 可不提交视频，先通过高质量截图验证产品页转化。

## 6. App 隐私

如果实际实现满足以下条件：

- 无广告 SDK。
- 无第三方分析 SDK。
- 无账号和服务器。
- 不上传项目、输入、结果和设备标识。
- 所有数据只保存在本机。

则 App Privacy 回答：

```text
No, we do not collect data from this app.
```

若后续加入分析、反馈上传、云同步或第三方 SDK，必须根据真实数据流重新回答，不能继续声明“不收集数据”。

隐私政策至少写明：

- 不创建账号。
- 不收集或出售个人数据。
- 项目和计算数据保存在用户设备。
- 导出和分享由用户主动发起。
- 删除 App 会删除本机数据，除非用户已导出备份。
- 支持邮箱和政策生效日期。

## 8. 出口合规与加密

如果 App：

- 不实现自研加密算法；
- 不提供 VPN、通讯加密、密码管理等加密功能；
- 仅使用 Apple 系统提供的标准网络安全能力访问支持页或隐私页；

通常可在构建中设置：

```xml
<key>ITSAppUsesNonExemptEncryption</key>
<false/>
```

最终回答必须以实际代码和使用的 SDK 为准。加入自定义加密、第三方网络库或特殊安全功能后重新评估。

## 9. 内容与知识产权

- 公式可自行推导或引用允许使用的公开资料。
- 不复制竞品的图标、界面、文案、图例和模板命名体系。
- 不内置未经许可的完整国家标准或行业标准正文。
- 可以引用标准编号和用户自行输入的数据，但应核实授权边界。
- App 名称、关键词和截图中不出现竞品名称。

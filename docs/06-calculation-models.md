# V1 计算模型与适用范围

本文档对应应用中实际展示的计算模板。内部计算使用 `double` 保留完整精度，界面四舍五入只影响显示。

## 单折弯

- 输入：成形外侧边长 `A、B`、内弯半径 `R`、板厚 `t`、折弯角 `θ`、K 因子。
- 折弯余量：`BA = π × θ / 180 × (R + Kt)`。
- 单边退让：`SB = (R + t) × tan(θ / 2)`。
- 折弯扣除：`BD = 2SB - BA`。
- 展开总长：`L = A + B - BD`。
- 适用：`0° < θ < 180°`，`0 ≤ K ≤ 1`。
- 不包含：材料回弹、折弯机模具修正和特殊压底工艺补偿。

## 同心圆锥台

- 输入：大端直径 `D`、小端直径 `d`、垂直高度 `H`、圆周等分数。
- 母线：`L = √(H² + ((D-d)/2)²)`。
- 展开外半径：`R₂ = LD / (D-d)`。
- 展开内半径：`R₁ = Ld / (D-d)`。
- 圆心角：`α = 360 × (D/2) / R₂`。
- 适用：`D > d > 0`。
- 直径按同一基准输入；结果不自动加入接缝和切割余量。

## 偏心圆锥台

- 输入：大小端直径、垂直高度、两圆心偏心距和圆周等分数。
- 大小端对应等分点分别建立三维坐标。
- 每条素线使用三维距离公式计算：`Lᵢ = √(H² + Δxᵢ² + Δyᵢ²)`。
- 点位从偏心方向开始，沿圆周编号。
- 当前模型要求小端投影位于大端投影范围内。

## 等角虾米腰弯头

- 输入：管径 `D`、中心弯曲半径 `R`、总转角 `θ`、节数 `n`。
- 相邻节转角：`β = θ / (n-1)`。
- 接口斜切角：`γ = β/2`。
- 圆管展开宽度：`C = πD`。
- 切口曲线按圆柱与斜平面相交模型计算，振幅为 `(D/2)tanγ`。
- 两端按半节处理，各接口等角分配。

## 圆管三通与相贯

- 输入：主管直径 `D`、支管直径 `d`、两轴线夹角 `θ`、支管圆周等分数。
- 以主管轴线和支管轴线建立三维坐标系，将支管圆周等分点代入主管圆柱方程。
- 对第 `i` 个圆周角 `φᵢ`：
  - 横向坐标：`yᵢ = (d/2)cosφᵢ`。
  - 主管表面坐标：`zᵢ = √((D/2)²-yᵢ²)`。
  - 沿支管轴线求交，得到相贯点高度。
- 支管展开宽度：`πd`。
- 当前版本要求 `d ≤ D`，轴线夹角位于 `10°–170°`。

## 天圆地方

- 输入：方口宽深、圆口直径、垂直高度、横纵偏心距和周长等分数。
- 方口周长与圆口圆周使用相同数量的参数等分点。
- 对应点建立三维坐标，每条素线用三维距离公式计算。
- 侧面积按相邻素线形成的梯形条带累加估算。
- 同心、单偏心和双偏心使用同一坐标模型；偏心量为 `0` 时即同心模型。

## 通用限制

- 展开图是按比例绘制的复核图，不是 1:1 打印模板。
- 结果不包含咬口、焊缝、折边、切割缝和用户工艺余量。
- 正式加工前应结合施工图、材料、设备和现场尺寸复核，必要时先制作试样。

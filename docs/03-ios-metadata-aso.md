# iOS 商品元信息与 ASO

## 1. ASO 目标

首发围绕“手机端钣金展开和放样计算”建立一个高意图词簇，不竞争泛工程、CAD、招聘、行情和竞品品牌词。

核心顺序：

1. 钣金展开
2. 手机钣金展开
3. 钣金展平
4. 钣金放样
5. 钣金展开计算器
6. 手机钣金展开计算器

## 2. 简体中文元信息

### App 名称

```text
钣金展开-放样展平计算器
```

- 字符数：12。
- 覆盖：钣金展开、钣金放样、钣金展平、钣金计算器、展开计算器。
- 符合用户要求的 `xxx-xxx` 格式。

### 副标题

```text
圆方过渡弯头三通下料与展开图
```

- 字符数：14。
- 覆盖构件和工作结果词。
- 不重复完整 App 名称。

### 关键词字段

```text
手机,风管,白铁,铁皮,板金,异形件,相贯线,圆锥,天圆地方,虾米腰,切割,排料
```

- UTF-8 共 98 字节，不超过 100 字节。
- “手机”可与名称组合成“手机钣金展开、手机钣金计算器”。
- “风管、白铁、铁皮”覆盖现场人群和材料俗称。
- “板金”覆盖常见异体搜索写法。
- “天圆地方、虾米腰”覆盖高意图现场俗称。
- 提交前必须在 App Store Connect 再次核对字节限制。

### 推广文本

```text
为钣金工、铆工、白铁工和风管现场设计。输入圆方过渡、弯头、三通、锥台等尺寸，离线计算展开数据并生成带尺寸展开图。一次购买，无广告、无订阅、无需注册。
```

推广文本不参与搜索排名，主要负责转化。

### 完整描述

```text
钣金展开是一款面向钣金工、铆工、白铁工、冷作工、风管加工和现场安装人员的离线放样与展平计算工具。

选择常用构件，按照示意图输入尺寸、角度、板厚和分段，即可查看展开尺寸、素线数据和带尺寸展开图。无需账号，不依赖网络，一次购买即可使用。

【常用钣金展开】

- 同心与偏心圆锥台
- 圆管变径和虾米腰弯头
- 等径三通与圆管斜交
- 正方锥台和矩形锥台
- 方管弯头与方管变径
- 同心、单偏心和双偏心天圆地方
- 单折弯和多折弯展开长度

【输入示意清楚】

- 每个参数都在示意图中标明位置
- 明确显示符号、名称和单位
- 自动检查无法成立的尺寸与角度
- 支持毫米、厘米和米
- 可保存常用尺寸作为个人模板

【结果便于复核】

- 显示母线、素线、弧长和关键点位
- 显示折弯余量、折弯扣除和 K 因子
- 支持不同小数精度
- 可复制单项数据或完整结果表
- 计算历史可随时复制并修改

【带尺寸展开图】

- 查看构件轮廓、切割线、折弯线和辅助点
- 支持缩放和平移
- 可切换尺寸与点位标注
- 导出高清图片或 PDF
- 添加到项目并批量保存

【完全离线】

- 一次购买，无广告、无订阅
- 无需注册或登录
- 核心计算不需要网络
- 项目和计算数据仅保存在本机
- 支持导出本地备份

适用人群：

钣金工、铆工、白铁工、管工、冷作工、暖通风管加工与安装人员，以及需要核对钣金展开尺寸的工程技术人员。

重要说明：

本 App 的结果基于用户输入和理想几何模型，用于辅助计算、学习与放样。实际加工尺寸会受到板厚基准、材料、咬口、焊缝、工艺余量、设备和现场误差影响。正式下料前，请结合施工图、现行规范、加工工艺和现场尺寸复核，必要时先制作试样。本 App 不替代工程设计、结构校核或专业人员判断。
```

## 3. 截图方案

建议 7 张 iPhone 竖版截图：

1. `钣金展开，输入尺寸立即计算`
2. `圆方弯头三通，常用构件快速找到`
3. `参数都在图上，输入不再靠猜`
4. `素线尺寸与点位，结果清楚可复核`
5. `自动生成带尺寸展开图`
6. `保存项目，图片PDF直接分享`
7. `一次购买·完全离线·无广告订阅`

首图要求：

- 展示“天圆地方”或“虾米腰弯头”真实计算界面。
- 同时看到输入示意图与计算结果。
- 主文案只保留“钣金展开，输入尺寸立即计算”。

第二至第五张必须使用不同构件，证明不是单一折弯余量工具。

不要展示：

- 尚未实现的 DXF 或数控机床功能。
- 竞品名称和商标。
- “绝对准确”“直接生产”“零误差”。
- 具体商品价格，避免调价后截图失效。

## 5. ASO 上线后调整

每周记录：

- 搜索曝光。
- 产品页浏览。
- 付费下载。
- 产品页转化率。
- 退款。
- 各关键词排名。

调整顺序：

1. 名称保留“钣金展开”至少 60 天，不频繁变更。
2. 先调整截图首图和副标题。
3. 关键词排名稳定后再替换低贡献关键词字段。
4. 根据用户搜索和反馈决定 V1.1 新增构件。
5. 不使用无关热词获取低转化曝光。

## 首发原则

首发版本只解决一个完整工作：

```text
选择构件
→ 查看示意图并输入尺寸
→ 计算展开尺寸与素线
→ 生成带尺寸的展开图
→ 保存、导出或分享
```

不做账号、云端计算、社区、行情、接单平台和自动续费。计算结果用于辅助放样和下料，实际加工前必须结合图纸、材料、工艺和现场尺寸复核。
